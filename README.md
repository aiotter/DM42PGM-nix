# Customised [DM42PGM](https://github.com/swissmicros/DM42PGM)

## How to use

1. Execute `nix build github:aiotter/DM42-mod` to build the DMCP5 program
2. Mount your DM42n (`SETUP` -> `System` -> `Reset to DMCP menu` -> `Activate USB Disk`)
3. Copy `DM42-mod.pg5` to DM42n
4. Unmount your DM42n
5. Load the program (`Load Program` -> Select `DM42-mod.pg5`)
